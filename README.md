本目录仅发布独立静态页面，不需要后端或外部脚本。来源为既有 Difficult_Airway_Case3/dist/index.html，托管迁移只更新浏览器标题，场景逻辑与参数保持原版本。

## 部署

使用GitHub Pages从main分支根目录发布。候选网址以GitHub Pages API返回值为准。平台部署成功及电脑访问成功不能代表手机关闭VPN后的网络验证通过。

## 正式二维码发布条件

必须获得用户在实体手机上的以下两项测试结果后，才能生成正式二维码：

- 关闭VPN，连接Wi-Fi，打开候选网址并确认监护仪加载、场景切换、声音可用。
- 保持VPN关闭，关闭Wi-Fi，使用蜂窝网络打开同一网址并确认相同功能。

在两项测试通过前，不生成新正式二维码、不覆盖旧二维码。原chatgpt.site二维码已经确认在用户普通网络下受阻，暂不分发。
